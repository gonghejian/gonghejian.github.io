最小产品不是功能最少，而是能够完整验证一个关键假设。

## 最小闭环

1. 用户提供真实输入。
2. 系统完成核心处理。
3. 用户得到可以判断好坏的结果。
4. 团队记录反馈并决定下一次实验。

> 本文件使用 `.mdx` 扩展名，V1 按 Markdown 内容读取，不执行 JSX 组件。

判断实验是否成立，需要同时观察**结果质量**和用户是否愿意继续使用。

| 环节 | 要验证的问题 |
| --- | --- |
| 输入 | 用户是否愿意提供真实材料？ |
| 结果 | 输出是否足以支持下一步行动？ |
| 反馈 | 用户是否能明确指出哪里有用？ |

```js
const experiment = {
  input: '真实任务',
  outcome: '可判断的结果'
};
```
