这是一个基于浏览器、模仿艺术家索尔·勒维特（Sol LeWitt）概念艺术风格的指令式绘图工具。用户通过输入文本指令（如“画100条随机方向的线”）生成几何图形作品，强调过程与概念而非结果。项目目前为免费展示页面，无商业功能。

### 2. 普通人如何低成本模仿？
**核心思路**：利用现有工具快速实现“指令生成图形”的最小可行产品（MVP）。

- **技术栈选择**  
  - 前端直接使用 HTML5 Canvas 或 SVG + JavaScript（可用 p5.js、Paper.js 等开源库）。
  - 无需后端：所有逻辑在浏览器运行，托管在 GitHub Pages 或 Netlify（免费）。

- **简化功能设计**  
  - 预设 10-20 个基础指令（如画线、网格、圆形），用户点击按钮即可生成。
  - 仅提供基础颜色、线条粗细调整，优先保证核心体验流畅。

- **内容与推广**  
  - 在 Reddit（r/creativecoding）、Twitter 等平台分享生成的作品图片，吸引概念艺术爱好者。
  - 发起“指令共创”活动，让用户提交创意指令，低成本积累内容。

- **成本控制**  
  - 使用免费图标资源（如 Feather Icons）和开源字体。
  - 若需存储用户作品，可用浏览器本地存储（LocalStorage）或免费云数据库（如 Supabase 免费 tier）。
