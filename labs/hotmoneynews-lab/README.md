*   **核心功能是“离线化”**：把网站变成单个二进制文件。这听起来酷，但用户群极其狭窄。谁会需要？开发者、需要存档的记者、在没网环境看文档的极客。这群人**付费意愿极低**，他们更愿意自己动手或找免费替代品。

*   **竞争激烈且免费**：`wget -r`、`httrack`、`SingleFile` 浏览器扩展、`monolith` 等工具早已存在且功能成熟。Kage 只是换了个壳（Rust写的，更“现代”），并没有颠覆性的差异化优势。用户为什么要为“一个更快的wget”付费？
*   **法律风险**：影子网站？这名字就暗示了灰色地带。如果有人用它来批量复制受版权保护的网站（比如新闻、教程、付费内容），作者可能面临DMCA下架或法律诉讼。这玩意儿是潜在的**法律炸弹**，没人敢为它投资。

**结论：这个项目目前是“为爱发电”的典型。想靠它赚钱？除非作者转型做SaaS，提供“一键离线化+托管”的企业服务，或者卖“离线化后的数据清洗/分析”服务。否则，它就是个漂亮的简历项目。**

    1.  **放弃Rust，用Python/Node.js**：Rust性能好但门槛高。用Python的`requests`+`BeautifulSoup`抓取，用`PyInstaller`打包成exe。或者用Node.js的`puppeteer`（无头浏览器）渲染后抓取，再用`pkg`打包。**成本：0元，时间：1周。**
