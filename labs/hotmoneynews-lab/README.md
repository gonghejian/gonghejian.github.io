# Carton Clock 项目分析

## 一、它怎么赚钱？

先说结论：**这个项目本身几乎不赚钱，它是一张"名片"，不是一门生意。** 作者 Niklas Roy 是柏林知名的装置艺术家/创客，这类作品的核心价值是**个人品牌与展览邀约**，而非产品销售。

可参考的变现路径（按可行性排序）：

- **展览/装置委托**：这类"用废弃物做的精密机械"是美术馆、科技馆、品牌快闪店的高价采购对象，单件委托可达数千到数万欧元。这是原作者的真实收入来源。
- **教学/工作坊**：把图纸拆成课程包，面向学校、创客空间、企业团建收费（人均 50–200 元/场）。
- **内容变现**：YouTube/B 站制作过程视频 → 广告分成 + 赞助（工具品牌、教育机构）。
- **开源图纸 + 付费套件**：图纸免费引流，卖"预切割纸板 + 五金件 + 摆锤配重"的组装套件（毛利 40–60%）。
- **IP 授权**：把设计授权给环保品牌做营销装置（"用我们的包装盒做时钟"），这是最容易被低估的一块。

**关键判断**：不要试图卖"纸板钟"本身——单价低、易损、物流贵、复购为零。要卖的是**体验、课程、展览和品牌合作**。

## 二、普通人如何低成本模仿？

### 第一步：先做出来（成本 < 100 元）

- **材料**：喝完的利乐包/牛奶盒 6–10 个（免费）、竹签或烧烤签（5 元）、钓鱼线（5 元）、硬币或螺母做摆锤配重（免费）、热熔胶枪（30 元）。
- **工具**：美工刀、钢尺、圆规、砂纸。**不需要 3D 打印机和激光切割机**——这正是这个项目的精髓：纯手工可复现。
- **核心难点在擒纵机构**（escapement），不是外壳。先去搜"纸板擒纵机构 / cardboard escapement"看 3–5 个拆解视频，理解"摆锤每摆一次放行一个齿"的原理，再动手。
- **预期**：第一版大概率走不准或停摆。**这是正常的**，把它当学习成本，别当失败。

### 第二步：降低门槛的替代方案

- 用**硬纸板 + 雪糕棒**替代利乐包做第一版原型，结构调通后再换包装盒做"颜值版"。
- 摆锤周期公式 T = 2π√(L/g)，**摆长决定走时快慢**——先算好摆长再定机身高度，能省掉大量返工。
- 齿轮用**现成塑料齿轮**（玩具拆件/淘宝几块钱一包）替代手剪纸齿轮，精度立刻上一个台阶。

### 第三步：把它变成"可传播的内容"

- 拍**延时 + 特写**：擒纵机构咬合的那 2 秒是全场最抓人的镜头，务必给微距。
- 标题公式：「我用 8 个牛奶盒做了个能走的钟」——**"能走"是钩子，"牛奶盒"是反差**。
- 发布到 B 站/小红书/抖音 + 同步英文版到 YouTube/Reddit r/DIY，一稿多投。

### 第四步：变现落地（选一条先跑通）

- **最快**：开工作坊。找本地书店、咖啡馆、亲子机构合作，收场地分成，材料成本极低，一人一场净赚几百到上千。
- **最稳**：做套件。淘宝/闲鱼挂"纸板钟 DIY 材料包"，先小批量 20 套测需求，卖不动就停。
- **最有天花板**：接商业装置。把作品照片整理成作品集，主动联系本地商场、环保品牌、科技馆做"废弃物再生"主题装置。

## 三、毒辣提醒

- **别高估"环保"卖点**：纸板钟不耐潮、不耐久，本质是"艺术装置"不是"实用产品"，宣传时别承诺耐用性，否则差评缠身。
- **别一上来就追求精度**：机械钟走时误差大是常态，你的卖点是"手工 + 反差 + 过程"，不是"精准计时"。
- **真正的护城河是"你会做别人不会做的机械结构"**，所以先把擒纵机构吃透，再谈商业化——否则你只是个卖纸盒的。
