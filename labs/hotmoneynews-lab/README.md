# 项目分析：Recalc（电子表格 + AI 终端单元格）

## 一、它怎么赚钱？

先说结论：**这个项目本身大概率不赚钱，它是一个典型的"开发者炫技型开源项目"**。但拆解它的商业化路径，有几条真实可行的线：

- **开源引流 → 卖托管版（SaaS）**：核心开源免费，但"团队协作、云端运行、审计日志、企业 SSO"做成付费云服务。这是最标准的开源商业化路径（GitLab、Supabase 模式）。关键点：AI 终端单元格需要 API Key 和算力，托管版天然有付费理由。
- **卖"AI 工作流模板"市场**：电子表格的价值在于模板复用。把"用 Claude 批量清洗数据""用 Codex 自动生成报表"做成模板包，按行业（财务、运营、爬虫）卖订阅。
- **企业私有化部署**：金融、医疗等不能把数据发给第三方 API 的行业，卖本地部署 + 私有模型接入的授权费。这是单价最高的一条线。
- **API 调用抽成/中转**：用户不想自己管 OpenAI/Anthropic 的 Key，你做一个统一计费的中转层，赚差价。风险是合规和毛利薄。
- **注意**：这个项目当前形态（HN 上的 Show HN）**没有护城河**——核心就是"单元格里跑 CLI"，技术上几天能复刻。所以真正的钱不在工具本身，而在**模板生态 + 企业信任**。

## 二、普通人如何低成本模仿？

**核心判断：不要模仿"电子表格+终端"这个壳，要模仿它的"最小可行洞察"——把 AI 能力塞进用户已经熟悉的界面里。**

可执行步骤：

- **第一步：砍到最小**。不做完整电子表格。用现成的开源表格库（如 `Handsontable` 社区版、`Univer`、或直接用 Excel/Google Sheets 插件），只做一个功能：选中单元格 → 调用 LLM → 回填结果。一周能出 demo。
- **第二步：选一个垂直场景，别做通用工具**。通用工具拼不过大厂。选"跨境电商批量写 listing""小红书批量改写文案""财务对账表自动分类"这类**有明确付费意愿的窄场景**。

- **第四步：分发靠"模板 + 教程"**。在小红书/B站/知乎发"我用 AI 表格 10 分钟干完一天的活"这类内容，模板免费送、进阶版收费。这是普通人最低成本的获客方式。
- **第五步：先卖再建**。做出 demo 后直接找 10 个目标用户（比如你认识的电商卖家）收 99 元试用，验证付费意愿再投入开发。**别先写完再找用户。**
- **避坑**：
  - 别碰"通用 AI 电子表格"——Google/微软/飞书都在做，你打不过。
  - 别自己搭模型推理，成本会吃掉所有利润。
  - 别指望开源项目本身变现，开源是获客手段不是产品。

**一句话总结**：这个项目的价值是"验证了 AI 嵌入熟悉界面的需求"，普通人该抄的是**这个思路 + 垂直场景 + 模板分发**，而不是抄代码。

  - 抓屏用 `ScreenCaptureKit`（macOS 12.3+，免费）

## 二、普通人如何低成本模仿？

## 一、它怎么赚钱？

**残酷现实：大概率不赚钱，或者只赚零花钱。** 每日谜题类产品（Wordle 是天花板）的变现路径极窄：

- **广告变现（最现实）**：日活几千时挂 Google AdSense / 赞助位，月入几十到几百美元。Wordle 在被 NYT 收购前也几乎没变现。
- **订阅制（难）**：$2–5/月解锁"无限模式/历史谜题/无广告/数据统计"。每日谜题用户粘性高但付费意愿极低——他们玩的就是"每天一次"的仪式感，付费点很难设计。
- **一次性买断/打赏**：$3 买断去广告，转化率通常 <1%。
- **B2B 授权/白标**：把谜题引擎卖给媒体、教育机构、企业内训做互动内容。**这是唯一有像样天花板的路径**，但需要销售能力，个人开发者基本做不动。

**结论**：把它当"作品集/流量入口/练手项目"可以，当"生意"要清醒——**每日谜题是典型的"高留存、零付费"品类**。
