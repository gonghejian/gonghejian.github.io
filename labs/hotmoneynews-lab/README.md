# 项目分析：3d-retro.com（复古 3D 技巧博物馆）

## 一、它怎么赚钱？

先泼冷水：**这个项目大概率不赚钱，也不打算赚钱。** CC0 协议意味着代码、素材全部放弃版权，任何人都能白嫖、商用、改头换面。这是典型的"技术人炫技 + 攒声誉"项目，不是生意。但如果你想从它的模式里榨出钱，有几条路：

- **流量广告变现（最现实）**：复古 3D 效果天然适合做"哇塞"型内容。挂 Google AdSense、Carbon Ads，或者接 Web3D/游戏引擎的赞助位。前提是流量得起来，HN 首页那波能带来几万 UV，但留存差。
- **付费教程/课程**：免费代码当钩子，卖"如何把这些技巧用到你的 Three.js 项目里"的进阶课。这是开发者社区最经典的漏斗。
- **接定制外包**：作品集本身就是最好的简历。客户看到"这人能做出这种效果"，直接私信下单。
- **赞助/捐赠**：GitHub Sponsors、Buy Me a Coffee。技术圈有情怀的人会打赏，但别指望养活自己。
- **卖周边/主题**：把复古 3D 美学做成付费模板、Shader 包、甚至 NFT（如果你不嫌丢人）。

**结论**：这不是商业模式，是个人品牌资产。想赚钱，得把它当"作品集 + 流量入口"，而不是"产品"。

## 二、普通人如何低成本模仿？

核心思路：**别做博物馆，做"一个爆款效果 + 一个能传播的壳"。**

### 1. 选一个具体效果，别贪多

- 从 Shadertoy、CodePen、Three.js Examples 里挑一个视觉冲击强的（比如伪 3D 隧道、老式 CRT 扫描线、Voxel 地形）。
- 用 AI（Claude/Cursor）把代码重写成"复制粘贴即用"的单文件 HTML。
- 目标：**一个效果，一个页面，一段可复制的 `<script>`。**

### 2. 用最便宜的栈

- **纯前端**：HTML + 原生 JS + WebGL/Canvas，零依赖，零构建。
- **托管**：GitHub Pages、Cloudflare Pages、Vercel 免费版，成本 0。
- **域名**：`.com` 一年 10 美元，或者直接用 `xxx.pages.dev` 白嫖。
- **总成本**：0～10 美元。

### 3. 内容结构照抄它的"可粘贴"卖点

- 每个效果配：**预览 + 一句话说明 + 可复制的代码块 + "Copy" 按钮**。
- 用 `<details>` 折叠代码，页面加载快，体验干净。
- 加一个"随机效果"按钮，增加探索欲。

### 4. 分发渠道（这才是关键）

- **Hacker News**：标题写 "Show HN: ..."，周二/周三早上发，效果最好。
- **Reddit**：r/webdev、r/threejs、r/javascript、r/InternetIsBeautiful。
- **Twitter/X**：录 5 秒 GIF，配文"paste this into your page"，技术圈传播极快。
- **Product Hunt**：包装成"开发者工具"发。
- **掘金/知乎/V2EX**：中文圈同步发，标题带"复古 3D"。

### 5. 低成本冷启动清单

- [ ] 选 3～5 个效果，别做 50 个。
- [ ] 单文件 HTML，手机能跑。
- [ ] 每个效果配 GIF 预览（用 ScreenToGif 或 Kap 免费录）。
- [ ] 加 "Copy code" 按钮和 CC0 声明（降低使用门槛）。
- [ ] GitHub 开源，README 写清楚"复制即用"。
- [ ] 发 HN + Reddit + X，一天内集中发。
- [ ] 看评论，把大家问最多的效果补上。

### 6. 避坑

- **别用 React/Vue 构建**：增加复制成本，违背"paste into a page"的卖点。
- **别做后端**：纯静态，省心省钱。
- **别追求完美**：先发 3 个效果，有人用再迭代。
- **别指望赚钱**：把它当作品集和流量入口，变现靠后续（课程、外包、赞助）。

# 项目分析：Reladraw

## 一、它怎么赚钱？

先泼冷水：**这个项目大概率赚不到钱，至少按现在的形态赚不到。** 它是一个开源工具型项目，定位是"图表的声明式语言"，核心卖点是"你自己决定元素放哪"。这类东西的商业模式天花板很低，原因如下：

- **目标用户是开发者/技术写作者**，这群人付费意愿极低，能白嫖绝不出钱。
- **竞品全是免费的**：Mermaid、D2、Graphviz、Excalidraw、tldraw，个个开源或免费增值，Reladraw 没有碾压性优势。
- **"精确控制布局"是反需求的**：大多数人画图要的是"自动排好"，而不是"我自己摆"。愿意手动摆的人，直接用 Figma/Excalidraw 拖拽更爽，为什么要学一门 DSL？

如果硬要设计变现路径，只有这几条，且都不性感：

- **托管服务（SaaS）**：免费本地 CLI，付费云端渲染、协作、版本历史、团队共享。参考 Excalidraw+ 模式，$6-8/月/人。但转化率会极低。
- **企业版**：私有部署 + SSO + 审计日志 + 与内部文档系统集成。卖给有合规要求的中大厂，客单价高但销售周期长。
- **IDE / 编辑器插件**：VS Code 插件免费引流，Pro 版收费（高级导出、模板库）。单价 $5-15 买断，走量。
- **模板 / 素材市场**：抽成。前提是生态起来了，冷启动阶段纯属幻想。
- **咨询 / 定制**：帮公司做图表自动化流水线。本质是接活，不是产品。

**结论**：这是一个"作品集项目"或"技术影响力项目"，不是生意。作者大概率也没想靠它赚钱，是在刷 GitHub star 和 HN 曝光，为个人品牌或求职铺路。

## 二、普通人如何低成本模仿？

先明确：**别模仿它的"产品"，模仿它的"打法"。** 它的价值不在于图表语言本身，而在于"用一个开源小工具撬动 HN 首页流量"这套路。

### 打法层（真正值钱的部分）

- **选一个"开发者天天用但体验烂"的细分场景**：不要做通用图表，做"某个具体痛点"。比如"K8s 架构图 DSL""数据库 ER 图 DSL""CI 流水线可视化 DSL"。越窄越好，窄到能一句话说清。
- **用 DSL / 文本格式切入**：文本天然适合 Git、适合 AI 生成、适合 diff。这是 2024 年后的大趋势——**让 AI 能生成的东西，必须是文本**。
- **开源核心 + 托管增值**：MIT/Apache 开源 CLI 和渲染引擎，云端协作收费。这是被验证过无数次的标准套路。
- **蹭 HN / Product Hunt / Reddit**：标题要具体、要有反差感。比如"我做了个图表语言，因为 Mermaid 排的图我看不下去"。情绪 + 具体 = 流量。
- **一周内做出 MVP**：解析器 + 渲染器，用现成库（如 ELK.js 做布局、SVG 直接输出）。别自己造轮子。

### 技术层（可执行清单）

- **语言设计**：别发明新语法，直接用 YAML 或 JSON 描述节点和坐标。降低学习成本，也方便 AI 生成。
- **渲染**：SVG 优先，浏览器和 CLI 都能用。用 `d3` 或直接手写 SVG 字符串。
- **布局**：既然卖点是"手动放"，那就别做自动布局，省掉最难的 80% 工作量。给个网格 + 吸附即可。
- **集成**：先做 VS Code 插件 + CLI，这两个是开发者入口。别一上来做 Web 编辑器。
- **AI 钩子**：写个 prompt 模板，让 ChatGPT/Claude 直接输出你的 DSL。这是 2024 年最好的冷启动手段。

### 成本控制

- **总投入控制在 2-4 周业余时间**，超过就说明方向错了。
- **不写文档网站**，README 写清楚就行。等有人用了再补。
- **不做用户系统**，托管版用 Stripe + 无服务器函数，别自建后端。
- **不追功能**，只做"一句话能说清的核心价值"，其他全砍。

### 心态层

- **别指望赚钱**，指望的是：GitHub star、HN 曝光、个人品牌、下一份工作或下一个项目的跳板。
- **如果 3 个月没起色，果断弃坑**，把精力投到下一个。这类项目 90% 会死，死得快是优点。

---

**一句话总结**：Reladraw 不是生意，是流量杠杆。你要抄的不是它的代码，是它"用极窄场景 + 文本 DSL + 开源曝光"撬动注意力的打法。
