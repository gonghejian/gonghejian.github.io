# 毒辣分析：WhodunnitAI 语音审讯侦探游戏

## 1. 它怎么赚钱？——大概率赚不到钱，除非转型

- **当前模式**：纯网页游戏，用户免费玩，无内购、无订阅、无广告。**零收入**。
- **隐性成本**：语音识别 + LLM 推理 + 实时对话延迟，每次游戏成本约 $0.5-2（按 GPT-4o 或 Claude 计费）。用户玩 10 次，你就亏 10 次。
- **可能的“伪收入”**：如果挂了 Stripe 捐赠按钮或 Patreon，那只是零花钱，撑不起服务器。
- **真正能赚钱的路径（如果创始人聪明）**：
  - **B2B 授权**：卖给密室逃脱店、剧本杀店、线下活动公司，作为“AI NPC 审讯系统”的 SaaS 工具，按门店月费 $99-299。
  - **企业团建/培训**：包装成“AI 沟通力训练”或“审讯技巧模拟”，卖给 HR 部门，按场次收费。
  - **数据变现**：收集用户审讯策略数据，卖给游戏公司做行为分析（但隐私风险大，不推荐）。
  - **付费 DLC**：每季新案件包，$4.99/个，但前提是用户留存率够高（目前看悬）。

**毒辣结论**：这个项目是“技术 demo”，不是生意。创始人要么快速转向 B2B，要么等着被大厂抄走。

---

## 2. 普通人如何低成本模仿？——3 天上线，成本 < $50

### 核心架构（全用现成 API，不写复杂代码）

- **语音输入**：浏览器 `Web Speech API`（免费）或 `Whisper API`（$0.006/分钟）。
- **AI 审讯逻辑**：`OpenAI Realtime API`（支持语音到语音，延迟 < 1 秒）或 `Claude + 语音转文字 + 文字转语音`（用 `ElevenLabs` 免费额度）。
- **游戏框架**：纯前端 `Next.js` + `Tailwind`，案件剧本用 JSON 写死（5 个嫌疑人，每个 20 条动态回应逻辑）。
- **部署**：`Vercel` 免费层 + `Supabase` 免费数据库存对话记录。

### 低成本模仿步骤（按天执行）

1. **Day 1**：写一个案件剧本（参考《东方快车谋杀案》结构），定义 5 个嫌疑人的性格、动机、谎言点。用 JSON 格式存储。
2. **Day 2**：接 `OpenAI Realtime API`，实现“用户说话 → AI 角色回应”的循环。提示词写死：“你是嫌疑人 X，你被指控谋杀，你撒谎时会结巴，你爱喝威士忌……”
3. **Day 3**：加 UI——嫌疑人头像（用 `DALL-E` 生成 5 张图，$0.04/张）、录音按钮、对话历史。部署到 Vercel。
4. **总成本**：API 测试费 < $10，域名 $10，其他全免费。

### 进阶差异化（避开同质化）

- **加“谎言测谎仪”**：用户审讯时，AI 会给出“心率波动”提示（其实是随机数 + 逻辑判断），增加游戏性。
- **多人审讯模式**：2-4 人同时提问，看谁先套出真相（用 `LiveKit` 免费层做语音房间）。
- **案件生成器**：让用户输入“凶手是厨师，动机是复仇”，AI 自动生成完整案件剧本（用 `GPT-4o` 一次生成，成本 $0.1）。

### 毒辣提醒

- **别做 App**，纯网页，否则审核和分发成本拖死你。
- **别做实时语音识别**，直接用 `Web Speech API`，省掉后端转写服务。
- **别做复杂剧情分支**，用“嫌疑人 3 条谎言 + 2 条真话”的简单逻辑，玩家问对了就触发关键线索，问错了就绕圈子。

这个项目证明了“语音交互 + 推理游戏”的可行性，但**商业模型是空的**。如果你要模仿，**只做 B2B 工具**（卖给密室逃脱店），别做 C 端免费游戏。3 天上线，拿 10 家店试水，每家收 $199/月，比做消费者产品靠谱 100 倍。
