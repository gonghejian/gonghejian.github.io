- 这项目本质是“SSH 隧道公共服务”——用户通过 `ssh ssh.place` 得到一个公网可访问的临时域名，把本地端口暴露出去（类似 ngrok 的极简版）。
- 收费模式？**目前没看到任何付费墙**。它靠什么活？要么是作者自掏腰包跑服务器（带宽、域名、维护），要么是赌未来用户量大了卖 Pro 版（自定义域名、固定子域、更长时效）。
- 现实：这种“免费工具型”项目，**99% 死在服务器账单上**。用户用完即走，没有留存，没有付费意愿。除非作者有 B 端客户（比如给内网穿透企业做定制），否则这就是个“技术 demo”，不是生意。
- 毒辣结论：**它不赚钱，它是在“用钱买名声”**（简历上写一句“我做了个 500 星的开源项目”）。如果你指望复制它赚钱，趁早醒。

## 2. 普通人如何低成本模仿？

**别模仿它的功能，模仿它的“套路”——但套路本身也不值钱。** 如果你非要干，按下面做：

### 最低成本方案（30 分钟内跑通）

- **用现成工具**：直接部署 [bore](https://github.com/ekzhang/bore) 或 [localtunnel](https://github.com/localtunnel/localtunnel)（开源，一行命令）。你只需要一台 5 美元/月的 VPS（比如 Vultr 最低配），装个 `bore server`，完事。
- **域名**：花 10 美元买一个 `.place` 或 `.link` 域名，配个通配符 `*.yourdomain` 解析到 VPS。**别学他用 `ssh.place` 这种单域名**，因为用户会撞车（同一子域冲突）。
- **核心代码**：不用写。`bore` 本身就支持自定义子域，你只需要写个 20 行的 shell 脚本，把用户请求映射到随机端口。

### 关键差异化（否则没人用你的）

- **加“限时链接”**：比如免费 1 小时，过期销毁——这能防止你的服务器被滥用（否则有人拿它挂钓鱼网站，你 IP 秒封）。
- **加“流量统计”**：告诉用户“你的隧道已转发 3.2MB”，增加一点粘性。
- **加“一键复制 curl 命令”**：很多用户是开发者在调试 webhook，你要让 `ssh -R 80:localhost:3000 yourdomain` 这条命令能直接复制粘贴。

### 运营成本（每月固定支出）

| 项目 | 费用 |
|------|------|
| VPS（1核 512MB） | $5/月 |
| 域名 | $10/年 |
| 带宽（按量） | 前 1TB 免费，超出 $0.01/GB |
| **合计** | **约 $6/月** |

### 但你要明白——这玩意赚不到钱

- 除非你把它做成“开发者工具链”的一部分（比如配合 CI/CD 自动暴露预览环境），否则用户不会付费。
- 唯一可行的收费点：**企业内网穿透**（给公司做私有部署，收一次性授权费）。但那是销售活，不是技术活。

## 最终毒辣建议

- **别做**。这个赛道有 ngrok（免费版够用）、cloudflared（免费）、bore（开源免费）。你做一个“更极简”的版本，没有护城河，没有用户粘性，只有账单。
- **如果你非要练手**：用 `bore` 部署，写个好看的前端页面，挂个“赞助”按钮（GitHub Sponsors），预期收入 = 0 到 每月 20 美元（来自好心人）。
- **真正的机会**：不是做“SSH 隧道”，而是做“隧道 + 监控 + 日志回放”的付费工具，面向调试 Webhook 的开发者。但那是另一个量级的项目，不是周末能搞定的。

**一句话总结：ssh.place 是技术玩具，不是商业项目。你模仿它，就是给自己找了一个每月 6 美元的电子宠物。**

# 毒辣分析：Handwritten Blogging Platform

## 1. 它怎么赚钱？（大概率：赚不到钱，或赚得很惨）

- **没有付费墙**：手写博客的核心是“慢”和“真实”，用户不会为慢内容付费。除非你搞“手写情书”订阅制，否则没人掏钱。
- **无广告位**：手写图片无法插入标准广告，就算插了，转化率也低得可怜。广告主不会投一个“看不清字”的页面。
- **无数据变现**：用户手写内容无法做关键词分析，无法卖用户画像。你连用户是谁都不知道，只能卖“情怀”。
- **可能的“伪盈利”**：卖周边（手写纸、钢笔）、收会员费（解锁更多手写模板）、或做“手写代笔”服务（帮懒人生成手写体图片）。但这些都是小生意，天花板极低。
- **最现实的收入**：靠“展示”引流到自己的付费课程/咨询（比如“教你如何做手写博客”）。本质是卖铲子，不是挖金子。

**结论**：这项目是“生活方式产品”，不是“商业产品”。赚钱靠的是创始人个人IP，不是平台本身。

---

## 2. 普通人如何低成本模仿？（3天可上线，成本<100元）

### 核心逻辑：不写代码，用现成工具拼装

- **用“手写板+扫描”替代开发**：买一块几十元的数位板（或直接用手机拍纸上的字），把文字写成图片，存为PNG。
- **用静态博客生成器**：用 **Hugo** 或 **Jekyll**（免费），把每篇手写图片作为文章主体，配一个简单的文字摘要（方便SEO）。
- **用“手写字体”骗过用户**：如果不想真手写，用 **“手写体字体”**（如“静蕾体”“方正手迹”），配合纸张纹理背景（CSS背景图），效果相似，成本为0。
- **用“定时发布”制造稀缺感**：每天只发一篇，模拟“手写日记”的节奏。用GitHub Actions定时推送，完全免费。
- **用“评论区”做互动**：接入 **Giscus**（基于GitHub Discussions），让用户用GitHub账号评论，无需自建服务器。

### 具体执行步骤（3天）

1. **Day 1**：注册GitHub Pages（免费），下载Hugo主题（搜“handwriting theme”），改背景为纸张纹理。
2. **Day 2**：用手机拍10张手写笔记（内容随便，比如读书笔记），用“扫描全能王”处理成白底黑字，存为图片。
3. **Day 3**：把图片按日期命名，写一篇“关于页”解释“为什么手写”，然后推送到GitHub，域名用免费的 `username.github.io`。

### 推广策略（不花一分钱）

- 在 **V2EX**、**Reddit** 的 `/r/slowweb`、**HN** 发帖，标题用“我放弃了AI，回归手写”这种反主流叙事。
- 在 **小红书** 发“手写博客”截图，配文“数字时代的反叛”，吸引文艺青年关注。
- 在 **即刻** 或 **Twitter** 上每天晒一张手写页，积累种子用户。
