### 2. 普通人如何低成本模仿？

普通人可基于开源思路，用最小成本实现类似功能。以下是可执行建议：

#### 核心思路：利用本地文件+现有AI工具模拟状态持久化
- **工具准备**：只需电脑、文本编辑器、免费AI API（如OpenAI API新账号有赠送额度）或本地模型（如Ollama）。
- **模仿步骤**：
  1. **创建三个Markdown文件**：
     - `memory.md`：记录历史对话摘要或关键信息。
     - `state.md`：存储当前任务进度、用户偏好等状态。
     - `knowledge.md`：添加自定义知识库（如项目规则、常见问答）。
  2. **用脚本或手动管理文件**：
     - 每次与AI交互时，将相关文件内容作为上下文提示词发送给AI。
     - AI回复后，手动或写简单脚本（如Python）更新文件内容。
  3. **使用现有工具简化**：
     - 用`Cursor`或`VS Code+插件`辅助代码编写和文件管理。
     - 利用`Git`进行版本备份，避免状态丢失。
  4. **低成本部署**：
     - 在`Replit`或`GitHub Codespaces`上免费运行脚本。
     - 如需自动化，可用`n8n`或`Zapier`免费版连接AI API和文件。

#### 注意事项：
- 模仿重点在**逻辑**而非代码：理解“状态持久化”是通过存储和读取上下文实现的。
- 优先解决自身需求：例如先为个人学习助手或项目管理工具添加记忆功能。
- 避免复杂化：初期无需完全复刻，用现有工具组合即可验证效果。

通过以上方式，普通人可几乎零成本模仿核心功能，并逐步迭代优化。
