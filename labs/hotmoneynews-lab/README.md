    *   **构建最小化产品**：先开发一个**VSCode扩展**或**命令行工具**，验证核心功能的价值。

*   **第四步：迭代与分享**

    *   **持续关注成本**：始终监控数据准备、训练和推理的成本，寻找优化点（如模型蒸馏、量化）。
