# 项目分析：代码构建的 3D 达芬奇博物馆

## 一、它怎么赚钱？

先说结论：**这个项目大概率不赚钱，甚至可能根本没打算赚钱。** 它是一个典型的"技术炫技 + 个人品牌"项目，挂在 Show HN 上是为了获得曝光和反馈。但如果你想把它当成一门生意，以下是可能的变现路径：

- **B2B 授权给博物馆/教育机构**：把引擎打包成"虚拟展厅 SaaS"，按年费或按展厅数量收费。卢浮宫、大英博物馆这类机构有数字化预算，但采购周期长、关系门槛高。
- **教育订阅制**：面向 K-12 学校或艺术培训机构，按学生席位收费（比如 $3-5/人/年）。卖点是"沉浸式艺术史课程"，而不是"3D 博物馆"本身。
- **NFT / 数字藏品**：把展厅里的 3D 模型做成限量数字藏品。2021 年能赚，现在基本凉了，不建议。
- **赞助与品牌植入**：找文化基金、艺术基金会赞助，在展厅里挂"由 XX 基金会支持"。这是非营利路线，收入天花板低。
- **技术咨询/外包**：真正的钱不在产品，在于"我会用代码做 3D 展厅"这个能力本身。接企业元宇宙展厅、车展、房展的活，单价 $2-10 万/项目。
- **流量广告/捐赠**：挂 Google AdSense 或 Patreon。以 Show HN 的流量规模，月收入大概率不到 $100。

**核心问题**：这类项目是"作品"不是"产品"。它没有解决一个付费意愿强烈的痛点，用户看完"哇好酷"就走了，没有留存和复购。

## 二、普通人如何低成本模仿？

关键认知：**不要模仿"达芬奇博物馆"，要模仿"用代码做 3D 展厅"这个方法论，然后换一个有人愿意付钱的题材。**

### 技术栈选择（成本从低到高）

- **最低成本路线（0 元）**：
  - 用 **Three.js** + **React Three Fiber**，浏览器直接跑，不需要下载引擎。
  - 3D 模型用 **Sketchfab** 上的 CC0/CC-BY 免费模型，或 **Poly Haven** 的免费资产。
  - 部署到 **Vercel / Netlify / Cloudflare Pages**，免费额度足够个人项目。
  - 代码托管 GitHub，用 GitHub Pages 也能白嫖。

- **中等成本路线（几百元）**：
  - 用 **Blender**（免费）自己建模或修改模型。
  - 用 **Spline** 做交互设计，导出到 Web。
  - 域名 + 服务器一年约 ¥200-500。

- **不要碰的坑**：
  - 不要一上来就学 Unity/Unreal，学习曲线陡、包体大、Web 导出体验差。
  - 不要买昂贵的 3D 扫描设备，先用免费资产验证需求。

### 题材选择（决定能不能赚钱）

- **选有明确付费方的题材**：
  - 本地房产中介的"VR 看房"——中介愿意为带看效率付费。
  - 本地博物馆/美术馆的"线上展厅"——有政府数字化预算。
  - 教培机构的"虚拟实验室"——物理/化学实验，学校有采购预算。
  - 车企/家居品牌的"产品 3D 展示"——营销预算充足。

- **不要选的题材**：
  - 纯艺术欣赏类（达芬奇、梵高）——用户觉得应该免费。
  - 通用"元宇宙空间"——太泛，没人买单。

### 执行步骤（4 周 MVP）

- **第 1 周**：选一个本地小客户（比如一家独立书店或咖啡馆），免费帮它做一个 3D 线上展厅，换取案例和推荐。
- **第 2 周**：用 Three.js + 免费模型搭出可漫游场景，重点做"手机端能流畅跑"，这是差异化。
- **第 3 周**：加一个"分享到微信/朋友圈"的按钮，和"预约到店"的转化入口。没有转化入口的 3D 展厅只是玩具。
- **第 4 周**：拿这个案例去谈 3-5 个同类客户，报价 ¥3000-8000/个。先收钱再优化。

### 差异化建议

- **做垂直，不做通用**：与其做"3D 博物馆平台"，不如做"专给独立书店的 3D 展厅工具"。
- **做移动端优先**：大部分竞品在手机上卡成 PPT，你把手机体验做好就是壁垒。
- **做"带转化的展厅"**：每个展厅必须能导流到购买/预约/留资，否则客户不会续费。

# Guitoro 项目分析

## 一、它怎么赚钱？

先泼冷水：**这类"键盘弹虚拟吉他"的玩具项目，本身几乎没有直接赚钱能力。** 它更可能是作者的引流作品集/技术展示。但如果硬要拆解变现路径，无非这几条：

- **订阅制解锁高级功能**：免费版给基础音色和有限和弦，付费解锁更多吉他音色、效果器（失真/混响）、录音导出、MIDI 输出。定价 $3–8/月。
- **一次性买断 Pro 版**：$10–30 买断，去掉水印、解锁全部音色包。这是工具类小项目最现实的路径。
- **音色包 / 采样包 DLC**：卖"民谣吉他包""电吉他失真包""尤克里里包"，每个 $2–5。本质是卖内容而非卖软件。
- **广告 + 联盟**：页面挂乐器电商（Sweetwater、Thomann）联盟链接，"想学真吉他？点这里"。转化率低但零成本。
- **B2B 授权**：把 Web Audio 引擎授权给在线音乐教育平台、网页游戏做嵌入式组件。这才是真正有想象空间的方向，但需要销售能力。
- **引流到付费课程/App**：如果作者本身做音乐教育，这个玩具就是漏斗顶端的免费钩子。

**残酷现实**：Web Audio 玩具的付费转化率通常低于 1%，月活几千的话月收入可能就几十到几百美元。别指望它养活你。

---

## 二、普通人如何低成本模仿？

核心结论：**技术门槛极低，难的是做出差异化和获取流量。** 以下是可执行路径。

### 技术栈（全部免费/开源）

- **音频引擎**：直接用 Web Audio API + [Tone.js](https://tonejs.github.io/)，Tone.js 自带采样器（Sampler）和合成器，几行代码就能加载吉他音色。
- **音色来源**：用 [FreeSound](https://freesound.org/)、[Philharmonia Orchestra 采样库](https://philharmonia.co.uk/resources/sound-samples/)（免费可商用）下载单音吉他采样，或用 [SoundFont](https://gleitz.github.io/midi-js-soundfonts/) 里的 guitar 音色。
- **键盘映射**：监听 `keydown`/`keyup`，把按键映射到品格和琴弦。用 `keydown` 触发拨弦，`keyup` 停止。
- **UI**：纯 HTML/CSS/SVG 画吉他指板，或直接用 Canvas。不需要框架，Vanilla JS 足够。
- **部署**：Vercel / Netlify / Cloudflare Pages，免费，绑定自定义域名一年也就 $10 左右。

### 低成本模仿步骤

- **第 1 步（1 天）**：用 Tone.js 的 `Sampler` 加载 6 个吉他单音采样，做一个"按一个键响一个音"的最小原型。先跑通声音。
- **第 2 步（2–3 天）**：设计键盘映射。比如 A/S/D/F/G/H 对应六根弦的空弦，数字键 1–5 对应品格，组合键触发不同音高。加一个"扫弦"键（如空格）一次性触发多弦。
- **第 3 步（2 天）**：画一个 SVG 吉他指板，按键时高亮对应位置，给视觉反馈。这是体验的关键，纯音频没人玩得下去。
- **第 4 步（1 天）**：加和弦预设。按 Q/W/E 触发 C/G/Am 等常用和弦，让小白也能"弹出歌"。
- **第 5 步（持续）**：加录音（`MediaRecorder` API）、导出 WAV、分享链接。这些是留存和传播的钩子。

### 差异化方向（别做第二个 Guitoro）

- **做垂直场景**：比如"键盘弹贝斯""键盘弹古筝""键盘弹 8-bit 游戏音效"，避开吉他红海。
- **做教学结合**：屏幕上显示简谱/六线谱，跟着弹，做成"键盘版吉他陪练"。
- **做社交传播**：生成"我弹的曲子"分享卡片，带二维码，利用社交裂变。
- **做移动端优先**：Guitoro 是桌面键盘逻辑，手机用户玩不了。做触屏版虚拟吉他，市场更大。

### 流量获取（比技术重要 10 倍）

- **发 HN / Reddit r/WeAreTheMusicMakers / r/webdev**：标题要具体，如"我用键盘弹出了《加州旅馆》"。
- **做 TikTok/抖音短视频**：录屏"键盘弹吉他"的猎奇视频，这类内容天然有传播性。
- **蹭 Product Hunt**：选周二发布，准备好 GIF 和一句话卖点。
- **SEO 长尾**：写"在线虚拟吉他""键盘弹吉他教程"等文章，挂自己的工具。

## 二、普通人如何低成本模仿？

核心逻辑：**用"认知偏差 + 即时反馈 + 社交分享"三件套，做一个 30 分钟能上线的单页互动。**

### 可执行步骤

- **选一个"人类直觉 vs 真实概率"的冲突点**
  - 随机性判断（本项目）
  - 颜色辨识 / 视错觉
  - 反应速度测试
  - 道德困境选择题
  - "你能听出 128kbps 和 320kbps 的区别吗"
  - 关键：**结果必须让人意外，且想截图分享。**

- **技术栈压到最低**
  - 纯 HTML + CSS + 原生 JS，一个文件搞定，部署到 Vercel/Netlify/Cloudflare Pages，**零成本**。
  - 不要上 React/Next，除非你要做多页。单页玩具用框架是自残。

- **交互设计三条铁律**
  - 3 秒内让用户知道要干什么。
  - 每轮反馈必须即时（对/错 + 动画 + 音效）。
  - 结束时给一个**可分享的分数卡片**（生成图片或带参数的 URL）。

- **传播钩子**
  - 标题用疑问句："你有多随机？""你能分辨吗？"
  - 结果文案要带挑衅性："你比 87% 的人更差。"
  - 一键分享到 X / 微信 / 复制链接。

- **冷启动渠道（按性价比排序）**
  - Hacker News Show HN（本项目用的就是这个）
  - Reddit 对应子版块（r/InternetIsBeautiful、r/webgames）
  - 小红书 / 即刻 / V2EX 发"我做了个小测试"
  - Product Hunt（如果包装得像产品）

- **成本清单**
  - 域名：$10/年（可选，用 vercel 子域名也行）
  - 托管：$0
  - 开发时间：4–8 小时
  - 总现金成本：**接近 0**

### 别踩的坑

- 别做需要登录、需要后端、需要数据库的东西——玩具就该是玩具。
- 别追求"完整产品"，追求"30 秒爽感"。
- 别指望它赚钱，把它当**流量实验 + 作品集**，赚的是曝光和机会。
- 别抄得太明显，换个领域（听觉、触觉、时间感知）比抄随机性更有新意。
