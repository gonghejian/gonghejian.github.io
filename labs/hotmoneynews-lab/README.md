### 1. 它怎么赚钱？——残酷现实：目前几乎赚不到钱

- **零收入陷阱**：纯WYSIWYG编辑器，无云存储、无协作、无高级功能，用户用完即走，无法形成付费闭环。
- **可能的“伪”收入点**（但当前未实现）：
  - **企业定制版**：向科研机构、出版社（如Springer、IEEE）出售“一键生成出版级图表”的插件，但需要大量销售团队。
  - **SaaS订阅**：增加云端协作、版本历史、模板库，按月收费（$5-10/月），但用户群太小（LaTeX用户本身小众）。
  - **广告/赞助**：在编辑器界面嵌入广告（如Overleaf的免费版），但会严重破坏用户体验，且收入微薄。
- **致命缺陷**：用户用TikZ是为了**免费+精确控制**，付费意愿极低。即使做成Overleaf的竞品，Overleaf本身也长期亏损，靠融资续命。

**结论**：当前项目是“情怀产品”，赚钱概率<5%。如果你要复制，别指望直接收费。

### 2. 普通人如何低成本模仿？——毒辣实操指南

**核心思路**：不要做“更好的TikZ编辑器”，而是做“TikZ的收割机”——用AI或模板库收割懒人用户。

#### 低成本模仿步骤（预算<500元，1周内上线）

- **第一步：用现成工具搭壳子**
  - 用 **CodeMirror** 或 **Monaco Editor**（VSCode内核）做代码编辑器，免费开源。
  - 用 **MathJax** 或 **KaTeX** 实时渲染LaTeX公式（已有现成库）。
  - 用 **D3.js** 或 **SVG.js** 做图形预览（TikZ本质是生成SVG）。
  - **成本**：0元，全部开源，1天搭建。

- **第二步：差异化“毒点”**
  - **毒点1：AI生成TikZ代码**。接入OpenAI API（成本极低），用户输入“画一个带箭头的流程图，3个节点”，AI自动生成TikZ代码。**这是唯一能赚钱的点**——按次收费（0.1元/次）或包月。
  - **毒点2：模板市场**。收集1000个TikZ模板（从GitHub、CTAN扒），用户下载需付费（0.5元/个）。**注意版权风险**，但普通人可先干再说。
  - **毒点3：一键导出“防修改”图片**。用户生成后，直接输出PNG/PDF，但免费版加水印，付费去水印（类似Canva套路）。

- **第三步：流量收割**
  - **SEO关键词**：抢“TikZ online editor”“LaTeX diagram tool”等长尾词，用免费博客（Medium/知乎）引流。
  - **病毒传播**：在Reddit的r/LaTeX、Hacker News发帖：“我用AI生成TikZ图表，比手写快10倍”，附上你的链接。
  - **变现路径**：免费版限制AI调用次数（每天3次），付费版无限。**定价**：9.9元/月，学生党会付。

#### 致命警告
- **不要碰桌面端**：纯Web端，用Electron打包成桌面版是死路（维护成本高）。
- **不要做社区**：用户只想要工具，不想社交。Overleaf的评论区功能几乎没人用。
- **不要做复杂功能**：只做“输入文字→生成TikZ→导出图片”三步，其他都是累赘。

**最终建议**：如果你不是LaTeX重度用户，别碰这个赛道。如果非要干，用AI+模板收割懒人，3个月后用户量上不去就立刻放弃。

### 2. 普通人如何低成本模仿？

**结论：非常容易，成本几乎为零。** 这个项目的核心是“3D数学 + Canvas 2D渲染”，没有用到任何高级API。

**低成本模仿步骤（按顺序执行）：**

*   **第一步：理解核心原理（1小时）**

    *   **渲染方式：** 不是真的渲染3D模型，而是将3D物体的顶点投影到2D平面，然后用`fillText()`在Canvas上绘制ASCII字符（如`@`、`#`、`.`）。字符的亮度/大小代表深度或光照。
    *   **关键文件：** 打开浏览器开发者工具，找到`glyphcss.com`的JS文件，直接复制它的`project()`和`render()`函数。这是合法的学习行为。

*   **第二步：搭建最小原型（2小时）**
    *   **工具：** 纯HTML + 原生JavaScript。不需要任何框架。
    *   **代码结构：**
        ```javascript
        // 1. 定义3D立方体的8个顶点坐标
        const vertices = [[-1,-1,-1], [1,-1,-1], ...];
        // 2. 定义12条边的连接关系
        const edges = [[0,1], [1,2], ...];
        // 3. 每帧循环：
        //    a. 旋转顶点（矩阵乘法）
        //    b. 投影到2D（透视除法）
        //    c. 清空Canvas
        //    d. 遍历edges，用moveTo/lineTo画线（或用fillText画字符）
        ```
    *   **关键技巧：** 先用`strokeStyle`画普通线条，调试通过后，再替换成字符渲染。

*   **第三步：增加“ASCII风味”（30分钟）**
    *   **字符映射：** 准备一个字符串如`" .:-=+*#%@”`，根据顶点到摄像机的距离（或光照强度），选择对应亮度的字符。
    *   **性能优化：** 不要每帧重新计算所有字符。可以预计算一个“字符纹理”，或者只渲染关键帧。
