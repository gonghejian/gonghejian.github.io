### 2. 普通人如何低成本模仿？（零成本起步，一周内上线）

别想着一步登天做SaaS。用“内容变现”路线，成本几乎为零。

*   **第一步：建立“数据管道”（1-2天，纯手动）**
    *   **工具：** 一个免费的Notion数据库或Airtable表格。
    *   **动作：** 每天花30分钟，手动浏览Hacker News的`/show`页面。只记录那些标题里带“AI”、“GPT”、“LLM”、“Agent”、“Copilot”等关键词的项目。
    *   **记录字段：** 项目名称、链接、一句话描述、创始人简介（如果有）、GitHub Star数（如果有）、你的**主观评分**（1-5分，基于“它解决什么问题？它用了什么AI模式？它看起来酷吗？”）。

*   **第二步：创造你的“评分体系”（1天，抄袭+微创新）**
    *   **抄袭：** 仔细读那篇博客文章，把作者提到的“设计模式”列出来（比如：RAG模式、Agent模式、Fine-tuning模式、Wrapper模式、Prompt Engineering模式等）。
    *   **微创新：** 自己加一个维度，比如“可复制性”（这个项目别人3天能抄出来吗？）或“商业潜力”（这个模式能卖钱吗？）。
    *   **动作：** 用这个体系，给你数据库里的每个项目打分。

*   **第三步：输出内容（持续，每天30分钟）**
    *   **平台：** 微信公众号、知乎专栏、即刻、Twitter/X、小红书。选一个你最擅长的。
    *   **内容形式：**
        *   **每日精选：** “今日最值得关注的3个AI Show HN项目，评分及点评”。（纯文字，300字以内）
        *   **每周总结：** “本周AI设计模式趋势：RAG模式泛滥，Agent模式开始冒头”。（配一张简单的趋势图，用Excel画就行）
        *   **深度吐槽：** “这个拿了1000 Star的项目，设计模式评分只有2分，为什么？”（吸引眼球，引发讨论）
    *   **关键：** 不要追求完美。你的核心是**持续输出**和**建立观点**。哪怕你的评分是错的，只要你有逻辑，就能吸引人。

*   **第四步：变现（第2周开始）**
