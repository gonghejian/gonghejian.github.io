# 玄学实验室 - Mystic Lab

生成时间：2026-01-21

## 项目简介

玄学实验室是一个集星盘绘制、解析和易经测算于一体的玄学工具集合。目前已完成星盘功能的基础版本。

## 功能特性

### 星盘功能（已实现）

- ✅ **星盘绘制**：可视化圆形星盘，包含12个宫位、12个星座、10大行星
- ✅ **星盘计算**：计算行星位置、宫位、相位等
- ✅ **星盘解析**：
  - 行星落座解读
  - 行星落宫解读
  - 重要相位分析
  - 综合解读

### 易经功能（规划中）

- ⏳ 时间起卦
- ⏳ 数字起卦
- ⏳ 手动起卦（三枚硬币）
- ⏳ 卦象可视化
- ⏳ AI 增强解卦

## 使用方法

1. 输入出生信息：
   - 出生日期
   - 出生时间
   - 出生地点（城市名称）
   - 时区选择

2. 点击"生成星盘"按钮

3. 查看星盘图和解析结果

## 技术说明

### 当前实现

- **前端技术**：纯 HTML/CSS/JavaScript，无需后端
- **星盘计算**：使用简化的天文计算公式（当前版本）
- **星盘绘制**：使用 Canvas 绘制
- **数据存储**：使用 localStorage 保存用户数据

### 精度说明

当前版本使用简化的天文计算公式，适合学习和演示使用。如需更高精度，建议：

1. 集成 Swiss Ephemeris WebAssembly 版本
2. 使用专业的天文计算库
3. 接入专业占星 API

### 未来改进方向

1. **提高计算精度**：集成 Swiss Ephemeris 等专业库
2. **增强解析功能**：接入 AI API 进行个性化解读
3. **易经功能开发**：实现完整的起卦和解卦功能
4. **UI/UX 优化**：改进界面设计和用户体验
5. **移动端适配**：优化移动设备显示效果
