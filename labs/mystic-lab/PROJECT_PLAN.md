# 玄学实验室项目方案

## 项目概述

**项目名称**：玄学实验室 (Mystic Lab)  
**定位**：一个集星盘绘制、解析和易经测算于一体的玄学工具集合

## 功能规划

### 第一阶段：星盘功能（核心功能）

#### 1.1 星盘绘制
- **输入**：出生日期、时间、地点（经纬度）
- **输出**：可视化星盘图表
- **技术要点**：
  - 使用 Canvas 或 SVG 绘制圆形星盘
  - 12 个宫位（1-12 宫）
  - 12 个星座位置
  - 10 大行星位置（太阳、月亮、水星、金星、火星、木星、土星、天王星、海王星、冥王星）
  - 相位线（合相、对相、三分相、四分相等）
  - 上升点、下降点、天顶、天底

#### 1.2 星盘计算
- **天文计算库**：
  - 使用 `swisseph` (Swiss Ephemeris) 的 JavaScript 版本
  - 或使用 `astrology.js` / `swe.js` 等库
  - 需要处理时区、夏令时等复杂问题

#### 1.3 星盘解析
- **基础解析**：
  - 行星落座解读
  - 行星落宫解读
  - 相位解读
  - 上升星座解读
- **AI 增强解析**（可选）：
  - 接入 AI API（如 DeepSeek）进行个性化解读
  - 结合用户问题生成针对性分析

### 第二阶段：易经功能（扩展功能）

#### 2.1 起卦功能
- **方式**：
  - 时间起卦
  - 数字起卦
  - 手动起卦（三枚硬币）
- **输出**：
  - 本卦、变卦、互卦
  - 六爻位置和阴阳
  - 卦象可视化

#### 2.2 解卦功能
- **基础解卦**：
  - 卦辞、爻辞
  - 卦象含义
  - 吉凶判断
- **AI 增强解卦**（可选）：
  - 结合用户问题生成个性化解读

## 技术选型

### 前端技术栈
- **HTML/CSS/JavaScript**：纯前端实现，便于 GitHub Pages 部署
- **Canvas 或 SVG**：用于星盘和卦象绘制
- **React**（可选）：如果复杂度较高，可考虑使用 React（参考 reading-lab）

### 天文计算库
- **首选**：`swisseph` 的 JavaScript 移植版本
- **备选**：
  - `astrology.js`
  - `swe.js` (Swiss Ephemeris JS)
  - 或使用在线 API（如 `astro.com` API，但可能有限制）

### 易经数据
- **64 卦数据**：需要完整的《周易》卦辞、爻辞数据
- **起卦算法**：实现传统起卦逻辑

### 数据存储
- **本地存储**：使用 `localStorage` 保存用户输入的出生信息、起卦记录
- **无需后端**：所有计算在前端完成

## 技术难点与解决方案

### 难点 1：天文计算精度
- **问题**：需要高精度的天文计算
- **解决**：使用成熟的 Swiss Ephemeris 库，这是占星学标准

### 难点 2：时区和夏令时处理
- **问题**：不同地区、不同历史时期的时区规则复杂
- **解决**：使用 `date-fns-tz` 或类似库处理时区，提供时区选择器

### 难点 3：星盘绘制复杂度
- **问题**：需要精确绘制圆形星盘、行星位置、相位线
- **解决**：使用 Canvas 或 SVG，参考开源星盘绘制库的实现

### 难点 4：易经数据整理
- **问题**：需要完整的 64 卦数据（卦辞、爻辞、象辞等）
- **解决**：从公开的《周易》文本中整理，或使用已有的开源数据
