# 弓箭品牌系统

## 品牌角色

gonghejian.cn 是 AI 时代个人系统的入口，也是自媒体矩阵的信任中枢。设计应呈现判断力、交付力、选择权，而不是普通个人博客或营销漏斗。

## 气质

- 冷静、克制、准确；
- 有思想密度，但不故作高深；
- 有专业感，但不模仿传统企业官网；
- 有个人辨识度，但不自我陶醉；
- 现代、可信、可长期使用。

## 视觉语言

- 以中性色和内容留白建立底盘；
- 使用一种主要强调色表达交互与品牌；
- 大面积背景需要有层次，可通过编辑式网格、轻材质、局部图形或内容结构建立，禁止无目的铺渐变；
- 阴影只表达层级，不装饰所有容器；
- 圆角必须来自组件角色，同层组件保持一致；
- 允许高质量摄影、抽象系统图或数据纹理，但必须与内容有关。

## 排版

- 界面默认使用系统无衬线字体；
- 品牌标题可谨慎使用衬线字体，但同一页面最多两套字体角色；
- 中文正文保持舒适行高，避免过细字重；
- 标题通过字号、字重和空间建立层级，不依赖全大写、标签或彩色胶囊。

## 禁止模式

- 卡片堆砌；
- 黑金“高端感”；
- 大面积无语义渐变；
- 装饰性 KPI；
- 每个区块都带图标、标签和按钮；
- 为填满画面而增加内容；
- 复制 Apple、Google、Linear、Notion 等产品的表面皮肤。
