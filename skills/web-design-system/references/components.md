# 组件规范

## Tokens

优先从 `assets/design-tokens.css` 复制并按页面语境调整。不要在同一页面创建多套间距、圆角和阴影体系。

## 间距

- 使用 4px 基础网格；常用间距为 8、12、16、24、32、48、64；
- 组件内部间距小于组件之间间距；
- 章节之间的空间必须明显大于字段之间空间。

## 容器

- 容器只用于表达分组或层级；
- 页面背景、主内容、浮层最多形成三个清晰层级；
- 同屏超过五个显著卡片时，先检查信息架构。

## 按钮

- 一屏原则上只有一个高强调主按钮；
- 使用动词描述结果；
- 点击目标至少 44×44px；
- 次要动作使用低强调按钮或文本动作；
- 危险动作不得与主动作同色。

## 表单

- 标签常驻，不只依赖 placeholder；
- placeholder 给示例，不重复标签；
- 默认只显示必要字段；
- 相关字段成组，补充字段使用展开区或下一步；
- 清晰区分客户原话、系统数据、顾问判断；
- 保存、错误和完成状态应即时反馈。

## 导航

- 导航表达位置或流程，不同时承担筛选、说明和状态展示；
- 流程型导航显示当前步骤与可预期的下一步；
- 移动端减少文字，保留位置感和返回路径。

## 数据与评分

- 只有影响判断的数据才常驻；
- 评分依据必须可解释；
- 无基线时显示“待验证”，不生成虚假精度；
- 辅助评分默认不应抢过主要任务。

## 状态与可访问性

- 所有交互控件具备 hover、focus-visible、active、disabled；
- 不仅依靠颜色表达状态；
- 正文和控件满足可读对比度；
- 支持键盘顺序、Escape 关闭弹层和语义化标签；
- 动画用于解释状态变化，保持短促并尊重 reduced motion。
