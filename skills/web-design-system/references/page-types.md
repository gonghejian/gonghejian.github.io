# 页面类型

## 品牌与内容入口

适用：首页、关于、白皮书入口、栏目页。

目标：建立身份与思想入口，引导理解和继续阅读。

设计重点：叙事顺序、编辑感、代表性内容、有限行动。允许更强的品牌背景与视觉构图，但不得压过核心判断。

## 实验室工具

适用：计算器、编辑器、访谈台、生成器、对话工具。

目标：让用户完成一个明确任务。

设计重点：任务路径、状态、输入输出、错误恢复、数据边界。默认一屏一个任务；高级能力渐进披露；工具界面不重复官网英雄区。

## 咨询型交付页面

适用：诊断、访谈、报告、提案、路线图、客户工作台。

目标：帮助客户理解问题、证据、判断与下一步。

设计重点：

- 像优秀咨询交付一样组织叙事，而不是模仿 PPT 装饰；
- 先结论，再证据，再行动；
- 用编号、章节、数据关系和留白建立权威感；
- 高级感来自精选信息、准确比例和内容编辑；
- 客户输入与顾问判断必须视觉分层；
- 敏感信息、假设、待验证项和正式结论必须有明确状态。

## 混合页面

若一个页面兼有品牌展示和工具操作，以用户当前任务为主。品牌只负责定调，不持续占用操作空间。
