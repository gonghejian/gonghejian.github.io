# 世界一流质量门槛

完成前逐项回答。任一核心项为“否”，继续迭代。

## 产品判断

- 能否用一句话说清这一屏的唯一任务？
- 默认信息是否都是当前必需？
- 是否把辅助信息后移或渐进披露？
- 主行动是否唯一且明确？
- 空状态、错误状态和完成状态是否成立？

## 视觉判断

- 第一眼是否知道看哪里、做什么？
- 页面是否有清晰的主次和空间节奏？
- 背景是否有层次但不喧宾夺主？
- 是否避免模板化卡片、胶囊、渐变和装饰数据？
- 字体、圆角、阴影、颜色是否来自统一体系？
- 去掉品牌名后，页面是否仍有专业完成度？

## 咨询交付判断

- 是否先结论，再证据，再行动？
- 客户事实、假设、顾问判断和承诺是否区分？
- 是否让复杂问题看起来更清楚，而不是更复杂？
- 是否有足够编辑感和克制，而非“后台系统感”？

## 工程判断

- 1440、768、390px 是否真实渲染检查？
- 长文本、真实数据、空数据是否检查？
- 键盘、焦点、弹层关闭和保存状态是否检查？
- Jekyll 构建和 `git diff --check` 是否通过？
- 临时截图、调试文件和敏感数据是否未进入发布物？

## 对标方法

选择 2–3 个同类一流产品，只比较：

- 信息密度；
- 首屏任务；
- 内容与控件比例；
- 交互状态；
- 响应式变化；
- 细节一致性。

不得因为“看起来像 Apple/Google/咨询公司”而判定通过。
