🇺🇸美国："更高更长"博弈

核心矛盾

服务业通胀粘性 vs 劳动力市场降温

乐观情景：CPI符合/低于预期

6-7月降息升温 → 黄金、新兴市场受益

悲观情景：CPI超预期

降息后移 → 美债 bear flattening → 科技股回调

战术应对

  • 数据公布前保持低Beta
  • 数据后根据方向右侧加仓
  • 关注10Y收益率4.5%/4.7%触发位
🇨🇳中国：政策发力 + 外部变量

内部主线

  • 房地产：一线限购松绑、存量房贷利率下调
  • 财政：超长期特别国债发行节奏
  • 信用扩张：政策意愿充足，实体需求疲软
外部变量（特朗普访华）：
若释放关税缓和、科技管制放松信号 → 风险溢价压缩，人民币汇率测试7.15下方
若仅"管控分歧"基调 → 利好出尽，防范短线回调
🔥中美关系：特朗普访华

中性情景 概率：中高

"管控分歧"基调，无具体关税承诺

市场：利好出尽，短线回调；底部抬高

悲观情景 概率：低

会谈破裂，伊朗问题无协调

市场：避险飙升；黄金、美元、美债涨

🎯战术交易方向

做多方向

  • 美债长端：10Y > 4.5% 逐步建仓
  • 黄金：回调至200日线加仓；若地缘缓和信号出现，短期承压
  • 港股高股息 + 科技：股息安全垫 + 中美关系弹性
  • 中概股/出口链：若访华积极，风险溢价压缩最受益

规避/对冲

  • 美股高估值SaaS/小盘科技：利率敏感 + 盈利放缓
  • 欧洲能源密集型工业：电价高企 + 需求疲软
  • 日元套息交易：BOJ正常化 + 波动率上升易unwind
