写给六个月前的自己：

如果你还喜欢写字，就早点用 Markdown。

不是因为 Markdown 多高级，而是它能帮你少处理很多无关动作，把注意力放回写作本身。

## 写作者总喜欢调整姿势

喜欢写字的人，常常喜欢折腾工具。

硬件、软件、博客系统、写作环境，都想优化一遍。这当然有风险：工具折腾太多，会变成逃避写作。

但合适的工具，也确实能促进写作。

它至少能帮助三件事：

1. 尽快进入专注状态。
2. 关注写作，而不是排版。
3. 让写作拥有版本记录。

## 保护心流

现在的信息干扰太严重。

微信、邮件、消息、待办事项，会把时间切碎。当一件事情需要高度集中时，只要启动被打断，就很容易从“待办”变成拖延。

写作尤其需要连续注意力。

Markdown 的好处，是让写作环境更接近纯文本。你不需要反复调格式，不需要在按钮和菜单之间切换，只需要把文字写出来。

## 关注写作而非排版

排版很消耗人。

写了很多文字之后，还要处理段落、行距、页面、标题，注意力就被带走了。

Markdown 把格式变成简单标记：

```markdown
# 标题
[链接](https://example.com)
**强调**
*斜体*
```

这些已经足够日常写作。

工具最重要的是保持最小启动。先用起来，再研究高级技巧。

## 让写作有版本记录

写作也需要版本控制。

Word 有修订记录，但和 Markdown 配合 Git 相比，仍然笨重。

用 Markdown 写作，再用 Git 管理版本，可以清楚知道自己什么时候改了什么，文章如何一步步变化。

这对长期写作很重要。写作不是一次成型，而是持续修改。

版本记录让修改有迹可循，也让文字成为可以长期维护的资产。

## 先用起来

工具不是目的。

Markdown、MacDown、Jekyll、Git，它们都只是让你更容易写、更容易管理、更容易发布。

先写起来，才是王道。
