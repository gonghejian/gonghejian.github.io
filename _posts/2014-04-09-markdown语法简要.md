Markdown 的价值，不只是语法简单，而是让写作更接近纯文本。

它减少排版干扰，让人先把内容写出来，再交给系统渲染。对博客、笔记、技术文档和长期知识库来说，这是一种很好的写作格式。

## 入门语法

常用语法很少，先掌握这些就够用：

- 标题：`#`、`##`、`###`
- 加粗：`**文字**`
- 斜体：`*文字*`
- 引用：`> 引用内容`
- 链接：`[标题](https://example.com)`
- 图片：`![描述](image.jpg)`
- 列表：`- 项目`
- 分割线：`---`

这些足以完成大多数文章。

## 进阶语法

进一步可以使用：

- 有序列表：`1. 2. 3.`
- 代码块：使用三个反引号包住代码
- 表格：用 `|` 分隔列
- 嵌套引用：用多个 `>` 表示层级

不要为了炫技使用复杂语法。Markdown 的优势是克制。

## 为什么适合写作

Markdown 适合个人知识系统，有三个原因。

第一，它轻。文件就是纯文本，容易保存、迁移和版本管理。

第二，它稳。格式不会强绑定某个软件。

第三，它能发布。Jekyll、GitHub、很多笔记工具和内容平台都支持 Markdown。

对长期写作来说，工具可能会换，但纯文本会留下。

## 写作先于排版

Markdown 给我的提醒是：先写清楚，再谈好看。

写作的核心是观点、结构、例子和表达。排版应该服务内容，而不是抢走注意力。

一旦习惯 Markdown，写作会更像搭建知识系统：文本、链接、图片、代码、引用，都能放在一个稳定结构里。
