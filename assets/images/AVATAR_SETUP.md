# 头像设置指南

## 📁 文件位置

将你的头像图片放在以下位置：

```
assets/images/avatar.jpg
```

或者

```
assets/images/avatar.png
```

## 📝 图片要求

- **文件格式**：JPG 或 PNG
- **文件大小**：建议 400x400px 或更高（正方形）
- **文件大小**：建议不超过 500KB
- **文件名**：`avatar.jpg` 或 `avatar.png`

## 🎨 推荐尺寸

- **最小尺寸**：200x200px
- **推荐尺寸**：400x400px
- **最佳尺寸**：800x800px
- **宽高比**：1:1（正方形）

## 📌 注意事项

- 如果头像文件不存在，系统会自动使用 `favicon.ico` 作为占位符
- 头像会显示为圆形
- 建议使用高质量的头像图片以获得最佳显示效果

## 🔧 使用方法

1. 将头像图片命名为 `avatar.jpg` 或 `avatar.png`
2. 放在 `assets/images/` 目录下
3. 刷新页面即可看到效果
