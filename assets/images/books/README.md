# 书籍封面图片目录

## 使用说明

1. **图片命名**：将书籍封面图片命名为 `book1.jpg`, `book2.jpg`, `book3.jpg` 等
2. **图片尺寸**：建议使用 200x300px 或更高分辨率（保持 2:3 的宽高比）
3. **图片格式**：支持 JPG、PNG、WebP 格式
4. **图片大小**：建议每张图片不超过 500KB，以保证页面加载速度

## 获取书籍封面

你可以从以下网站获取书籍封面：
- [豆瓣读书](https://book.douban.com/)
- [Amazon](https://www.amazon.com/)
- [Google Books](https://books.google.com/)

## 注意事项

- 确保图片版权合规
- 如果图片不存在，系统会自动使用占位符
- 建议使用高质量的图片以获得最佳显示效果
